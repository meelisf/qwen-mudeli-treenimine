# Skriptide arhiiv

Siin on skriptid, mis ei ole enam aktiivses kasutuses: vana treeningliin, varasemad
andmestiku versioonid (kurrent v1–v5, Dresdner, Bullinger, Escher jne), vanad
hindamisskriptid ning ühekordsed proovid, silumised ja auditid (sh Vasar 1932
klapitus, tehtud 17.10.2026). Tõstetud siia 2026-11-02 (`git mv`, ajalugu säilib).

Need EI OLE otse käivitatavad: paljud impordivad `scripts/`-i ühismooduleid
(`imaging`, `prompt`, `lyhend_makron` …) või üksteist. Kui midagi on vaja uuesti
kasutada, tõsta fail tagasi `scripts/`-i.

Aegunud OCR-juhis (`INSTRUCTION_CS`, suhteline `<cs>`) on `scripts/prompt_archive.py`-s —
mitte siin, sest OCR-teenus kasutab seda kuni uue `<f>`-mudeli tootmisse minekuni.
